PROJECTS

Explainable Early Sepsis Prediction Using Temporal Deep Learning and XAI

Develop an explainable deep learning model for early sepsis prediction using ICU time-series data.

QuantaDOT

A low-cost Arduino-based educational robot that transforms passive smartphone usage into an interactive STEM learning experience. The robot supports Bluetooth control, voice command control, and autonomous obstacle avoidance, enabling students to explore robotics, embedded systems, and intelligent navigation through hands-on learning.

Loan Management Prediction

The Loan Management System is a Machine Learning-based web application designed to assist financial institutions in evaluating loan applications and predicting loan approval outcomes. By analyzing applicant information such as income, education, employment status, credit history, loan amount, and other financial attributes, the system predicts whether a loan should be approved.

HopeHub

HopeHub is a community-driven web platform developed to simplify the process of donating, volunteering, and requesting assistance. The platform acts as a bridge between donors, volunteers, non-governmental organizations (NGOs), and individuals in need by providing a centralized system for managing donations, campaigns, volunteer activities, and requests.

ESP32-CAM Based Surveillance Car

The ESP32-CAM Surveillance Robot is a Wi-Fi-controlled robotic vehicle that combines real-time video streaming with wireless navigation. Built around the ESP32-CAM module, the robot allows users to remotely monitor environments while controlling movement through a web interface.

Phoenix Mart

Phoenix_Mart is a relational database project developed as a complete online shopping management system. The project demonstrates the design and implementation of an efficient database capable of handling every major operation of an e-commerce platform, including customer management, product cataloging, inventory control, order processing, payment management, discounts, shopping carts, and customer reviews.

Rokto Lagbe

Rokto Lagbe is a web-based Blood Bank Management System designed to make blood donation and blood requests more efficient, transparent, and accessible. The platform connects blood donors, recipients, hospitals, and administrators through a centralized system, enabling quick access to blood availability during emergencies.
