Explainable Early Sepsis Prediction Using Temporal Deep Learning and XAI

An explainable deep learning model for early sepsis prediction using ICU time-series data.

QuantaDOT

A low-cost Arduino-based educational robot that transforms passive smartphone usage into an interactive STEM learning experience. The robot supports Bluetooth control, voice commands, and autonomous obstacle avoidance.

A Machine Learning-based web application designed to assist financial institutions in evaluating loan applications and predicting loan approval outcomes. The system analyzes information such as income, education, employment, credit history, and loan amount.

ESP32-CAM Based Surveillance Car

A Wi-Fi-controlled robotic vehicle combining real-time video streaming with wireless navigation. The ESP32-CAM allows users to remotely monitor environments while controlling the robot through a web interface.

Phoenix Mart

A relational database project developed as an online shopping management system. It covers customer management, products, inventory, orders, payments, discounts, shopping carts, and reviews.

Rokto Lagbe

A web-based Blood Bank Management System designed to make blood donation and blood requests more efficient, transparent, and accessible. The platform connects donors, recipients, hospitals, and administrators.
